# Features

What the template ships, with stable IDs per area. Status: ✅ works, 🧪 built, not yet run on a board, 🚧 in
progress, 📋 planned, 🐛 bug. Update this file in the same commit as the code; never renumber or reuse an ID.

## FW: firmware (`firmware/`)

| ID | Feature | Status | Notes |
|---|---|---|---|
| FW-1 | embassy on STM32G0B1CE, defmt log over RTT | 🧪 | generated by embedded_bedrock's firmware template, see `bedrock_fw.json` |
| FW-2 | WireWeaver device API served over USB | 🧪 | `firmware/src/ww.rs` |
| FW-3 | Settings store in flash (`ww_settings`, 8 KiB at the end of the flash, ECC-safe reads) with the board's label | 🧪 | `firmware/src/settings.rs` |
| FW-4 | `cnt` event counters in RAM and in backup registers (survive a reset) | 🧪 | `cnt tui` shows them |
| FW-5 | Crash capture: HardFault and panic record kept across a reset, reset cause, boot counter | 🧪 | `bedrock_crash`, `firmware/src/last_reset.rs` |
| FW-6 | ES0548 (dual-bank prefetch) guard: flash prefetch on, code kept in bank 1 by a link-time assert | 🧪 | `firmware/memory.x` |
| FW-7 | Clock tree for the CANnify Micro | 🧪 | `firmware/src/main.rs` |
| FW-8 | The device suite (`device` in the API) | 🧪 | `firmware/src/ww/device.rs` |
| FW-9 | D14 breathes by default: TIM15_CH1 PWM on PB14 at 1 kHz through embedded_bedrock's `bedrock_led`; `led_on` / `led_off` hold it solid; `leds` (mode, brightness, identify); embassy's time driver named explicitly (TIM4) so TIM15 stays free | 🧪 | `firmware/src/led.rs`, `src/ww/leds.rs` |
| FW-10 | Shared clock steered by the host (`clock`, `ww_timebase::Clock` through `bedrock_sync`'s ClockServer, U32 µs); breath and blink aligned to shared time, so boards on PCs with NTP breathe in phase | 🧪 | `firmware/src/sync.rs`, `src/ww/clock.rs` |
| FW-11 | `pins`: `ww_pin_diag::PinDiag` on the 27 pins the board map marks free, named as there; analog until a host sets or reads a pin, back to analog on `release_all`, on a disconnect and when the host goes silent; `#[claim(exclusive)]` | 🧪 | `firmware/src/pins.rs`; the list is checked against the pin table by `cannify_micro_client/tests/board_pins.rs` |

## HOST: client library and command line

| ID | Feature | Status | Notes |
|---|---|---|---|
| HOST-1 | `cannify_micro_client`: typed methods over the generated client, one error type, `raw()` for the rest | 🧪 | |
| HOST-2 | `cannify` command line: `probes`, `info`, `led on\|off\|blink`, `label`, `last-reset`; colour, `--version` with git SHA and build time | 🧪 | |
| HOST-3 | Shell completion with live values (probe serials, ELF files) for bash, zsh and fish | 🧪 | `COMPLETE=bash cannify` |
| HOST-4 | `cannify leds show\|mode\|brightness\|identify`; client `leds_mode`, `brightness`, `identify` | 🧪 | `cannify_micro_client/src/sync.rs` |
| HOST-5 | `cannify clock [--watch N] [--timeout S]`: waits for the lock, prints the residual (shared time minus UTC), the round trip it is known to, slew, error bound and the fit's rate; client `clock_steering`, `wait_clock_locked`, `clock_check` | 🧪 | `cannify_micro_client/src/sync.rs`; the connection steers the clock by itself (WireWeaver's clock sync, `WW_CLOCK_SYNC=off`) |
